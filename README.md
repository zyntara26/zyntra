## 🎨 Design System: Cosmic Kinetic Glass

Engineered with the **Cosmic Kinetic Glass** design language:
- **Palette**: Deep cosmic surfaces (`#0f131e`, `#171b27`, `#1b1f2b`), vibrant electric cyan accents (`#5de6ff`), and royal violet glows (`#6d28d9`, `#d3bbff`).
- **Typography**: Space Grotesk for display heroes and technical labels; Plus Jakarta Sans for body prose.
- **Glassmorphism**: Backdrop blur filters (`backdrop-blur-xl`, `backdrop-blur-2xl`) layered over atmospheric radiant glows.
- **Micro-Interactions**: Ambient glowing badges, interactive FAQ accordions, mobile drawer navigation, live inquiry transmission simulators.

## 🛠️ Tech Stack

- **HTML5 & Modern Semantic Web Standards**
- **Tailwind CSS (JIT via CDN Engine)** with custom extended tokens
- **Google Fonts**: Space Grotesk & Plus Jakarta Sans
- **Google Material Symbols Outlined**
- **Vanilla JavaScript**: Lightweight, zero-dependency interactivity for menus, dropdowns, accordions, and asynchronous form state transitions.

## 🚀 Deployment Options

### Render (Static Site - Free & Automatic)
1. Push your code to your GitHub repo ([`https://github.com/zyntara26/zyntra.git`](https://github.com/zyntara26/zyntra.git)).
2. Log into [Render Dashboard](https://dashboard.render.com).
3. Click **New +** > **Static Site**.
4. Select `zyntara26/zyntra` repository.
5. Configuration (pre-filled via `render.yaml`):
   - **Name:** `zyntara`
   - **Branch:** `main`
   - **Build Command:** *(leave blank)*
   - **Publish Directory:** `public`
6. Click **Create Static Site**. Render will deploy your site on a free `*.onrender.com` domain with automatic SSL and global CDN!

### GitHub Pages
1. In your GitHub repository, navigate to **Settings > Pages**.
2. Under **Build and deployment > Branch**, select `main` branch and `/ (root)` folder.
3. Click **Save**. Within 1–2 minutes, your website will be live at `https://<username>.github.io/<repo>/`.

### Vercel / Netlify / Cloudflare Pages
- Connect your GitHub repository to Vercel, Netlify, or Cloudflare Pages.
- Framework Preset: **Other** / **Static Site**.
- Build Command: *(leave empty)*
- Output Directory: *(leave empty or `.`)`
